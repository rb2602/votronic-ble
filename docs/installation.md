# Installation

## Install

[![Open your Home Assistant instance and open the Votronic Bluetooth repository in the Marketplace.](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=rb2602&repository=votronic-ble&category=integration)

1. Click the button.
2. Click `Install`.
3. Set up the integration, see [Pairing](pairing.md).

If the button does not work, search for `Votronic Bluetooth` under
`Settings -> Marketplace`.

Without the Marketplace: copy `custom_components/votronic_ble` from a
[release](https://github.com/rb2602/votronic-ble/releases) to
`/config/custom_components/votronic_ble` and restart Home Assistant.

## Update

New versions appear under `Settings -> System -> Updates`. Install, then
restart Home Assistant.

## Uninstall

1. Remove `Votronic Bluetooth` under `Settings -> Devices & services`.
2. Under `Settings -> Marketplace`, open `Votronic Bluetooth` and select
   `Uninstall` in the menu.
3. Restart Home Assistant.
